# 疯狂水世界 · 航行控制台

![Node.js 20.11+](https://img.shields.io/badge/Node.js-20.11%2B-417E38) ![Windows](https://img.shields.io/badge/Windows-本地控制台-0078D4) [![仅供学习交流](https://img.shields.io/badge/license-Study%20Only-orange)](LICENSE)

在本机管理《疯狂水世界》账号，直连游戏 WebSocket，安排领奖、基地经营、英雄养成和舰队任务。每个账号独立保存开关、详细配置和用量记录，运行日志会说明实际完成的操作、收益及跳过原因。

## 快速开始

需要 Windows 和 Node.js 20.11 或更高版本。请先在电脑版微信中打开一次《疯狂水世界》，供工具读取本机游戏协议包。配置表和世界地图默认从游戏 CDN 自动更新。添加抖音账号还需要登录本机的电脑版抖音。

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
npm ci
npm start
```

默认控制台地址为 `http://127.0.0.1:17321/`。

1. 进入 **账号**，选择 **从电脑微信添加** 或 **从电脑抖音添加**。提示正在采集后，从对应客户端重新进入游戏，核对角色验证结果。益世界 APP 账号可使用 **APP 账号登录**，选择账号密码或短信验证码，从列表中选择区服和游戏角色，保存并连接。设备档案会在首次登录或获取验证码时自动生成并保存，后续持续复用。[APP 登录步骤](docs/console-guide.md#手机号登录)
2. 在 **游戏配置** 设定项目、资源保留和预算，可先用 **只读预览** 查看当前计划。保存配置不会启动挂机。
3. 进入 **挂机** 开启所需模块并开始运行。首次可将轮数设为 `1`，核对日志与收益。`0` 表示持续运行。
4. 挂机开始后可关闭网页，请保持启动窗口打开、电脑唤醒。关闭启动窗口或按 `Ctrl+C` 会结束进程。

手动进入游戏操作时，按 **暂停托管 → 进入游戏操作 → 退出游戏 → 恢复托管** 执行，再按原流程开始挂机。自动重连和接管时的生产同步规则见使用指南。[持续运行与自动恢复](docs/console-guide.md#持续运行与自动恢复)

> 请只用自己的账号测试。自动化操作会改变游戏内的资源和进度，使用第三方工具有账号处罚风险。采集凭证会临时更改当前 Windows 用户的代理和证书设置。账号凭证与账号导出文件含登录信息，请留在本机。

## 功能一览

页面按 **总览 / 挂机 / 游戏配置 / 建筑一览 / 挑战 / 资源与玩法 / 账号** 分组。挂机页管理启停，游戏配置管理细项、策略、消费权限和参数。

运行状态按各玩法显示检查结果与执行条件，博物馆探宝和海兽培育的总开关汇总各自子项的计划。

| 分组 | 主要功能 |
| --- | --- |
| 基地与生产 | 建筑、工厂、农田、贸易港、居民订单、采集与钓鱼 |
| 养成 | 英雄与阵容、藏品、海兽培育、博物馆、装备制造与锻造 |
| 世界与挑战 | 海盗首杀与扫荡、世界 Boss、货轮、城战、战后维修、联盟情报、主线与试炼 |
| 联盟与硅矿 | 募兵与互助、商船、工事捐赠、三舰队硅矿配置 |
| 日常与活动 | 免费奖励、邮件、不差钱商人、海商王、超凡英雄活动及按开放状态显示的活动 |
| 总览与工具 | 只读地图、活动统计、排行榜、礼包兑换、运行日志与账号管理 |

各玩法的默认开关、资源限制、调度顺序与确认方式保存在使用指南。[完整功能与规则](docs/console-guide.md#功能一览)

在 **游戏配置 → 基地 → 居民需求 → 不准消耗** 选择要保留的材料。自动居民需求开启后，角色 12 级起会协商含这些材料的订单。协商期间继续处理其他订单，等服务器更新需求后再决定交付或继续协商。

不差钱商人的状态、订单材料、单次操作和全部活动开关统一位于 **资源与玩法 → 活动 → 不差钱商人**。在活动详情中设置自动完成订单、缺材料时允许消耗钻石、自动领取最终奖励，修改后按账号自动保存。活动未开放、账号未连接或暂停时也能配置，已有选择会继续使用。自动完成与钻石补料默认关闭，钻石消费受全局总开关、每日预算和保留量限制。

超凡英雄在活动页归入周期活动，总开关、自动挑战、战败重试次数、自动完成订单、自动转盘抽奖和达标奖励统一位于 **资源与玩法 → 活动 → 超凡英雄活动**。设置按账号自动保存，已有选择继续使用。重试默认 10 次，自动挑战与转盘默认关闭，转盘消耗已有英雄副本抽卡券。

海商王归入周期活动，自动走商、领奖、情报共享、采购策略、指针加速与补购、利润上限、首趟时间和商船升级统一位于 **资源与玩法 → 活动 → 海商王**，修改按账号自动保存。未开放、未连接或暂停时可预先配置，原有参数和开关继续使用。购买指针和升级商船同时受全局钻石开关、预算及保留量限制。

活动页展示服务端已下发的起止时间，未开放与已结束的期次默认收起，并按账号保存历史。超凡英雄、不差钱商人、海商王的预配置入口归入“未开放活动”，展开后可编辑，读取到开放期次后自动移到上方。已开启的任务随挂机按主活动、子活动的有效时间自动启停，复开时继续使用保存的选择。未来日程取决于服务端下发范围，历史从实际读取后开始留存。

建筑一览提供需求联合排产，读取当前订单、已开启的消费备料、库存及生产队列，按用户设置的需求优先级逐级优化齐套时间。上游材料继承需求优先级，共享设备排队，独立设备并行，结果展示分层工期上下界、逐批投料与最优性证明状态。[需求联合排产](docs/console-guide.md#需求联合排产)

城战支持逐队设置进攻或防守，并独立设置两侧的目标来源、城市名单和优先策略。[城战攻守目标](docs/console-guide.md#世界与挑战)

广告任务各入口默认关闭。有免广告权益时立即领取，已开启的任务也支持无权益账号等待后直接领奖。无权益流程存在服务器识别和账号处罚风险，启用前请阅读具体说明与已有验证范围。[广告奖励](docs/console-guide.md#广告奖励)

## 配置与预算

- 游戏配置按账号自动保存，保存或只读预览不会启动挂机。有限轮数只保留参数，持续挂机可在重启后恢复。
- **钻石总开关默认关闭**，每日总预算默认 `2000`，钻石保留阈值默认 `0`。日预算为 `0` 时禁止自动花钻石，各项目限制与总预算同时生效。
- 发送前先占用预算。明确未发送或被拒绝时释放，结果未知时保留额度与防重记录，后续读取业务证据后确认。重启或保存配置不会清空未知记录。
- 材料、金币和舰队预留与持久账本配合。配置保存在 `data/automation-settings.json`，用量与防重记录保存在 `data/automation-usage.json`，按北京时间零点换日。

旧配置兼容、订单预留、玩法开关及活动恢复规则见使用指南。[配置与预算细则](docs/console-guide.md#配置与预算)

## 数据与问题排查

- `data/` 包含账号凭据、设置、账本和日志。配置导出只包含玩法设置，账号导出包含登录凭据。
- `work/` 保存本机协议、配置与素材缓存。`certificates/` 保存抓包证书与代理备份，采集恢复记录保存在 `data/capture-session.json`。
- 控制台只监听 `127.0.0.1`，没有登录校验。手机访问需自行搭建带鉴权的隧道。
- 异常退出后，启动自检会提示上次采集残留。可在账号页恢复，或运行下表的 `recover` 命令。

遇到功能未执行或持续待确认，请先保留 `protocol.log` 和 `protocol.log.1`，结合发生时间、配置与实际结果反馈。完整排查步骤和附件要求见使用指南。[问题反馈日志](docs/console-guide.md#问题反馈日志)

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm start` | 构建界面并启动控制台，默认端口 `17321` |
| `.\start-console.cmd` | 使用 Node 启动入口，端口 `17323`，输出地址与实时日志 |
| `node tools/start-console.mjs` | 直接使用上述启动入口 |
| `.\start-console.cmd status` | 检查抓包证书和上次采集恢复记录 |
| `.\start-console.cmd recover` | 恢复上次采集留下的代理和证书改动 |
| `npm run build:ui` | 重新构建控制台页面与样式 |
| `npm run test:offline` | 运行无需本机游戏协议包的核心回归 |
| `npm run typecheck` | 检查持久化与用量账本的类型约束 |
| `npm test` | 构建界面并运行全部回归，包含真实协议编解码验证 |
| `npm run sync-resources` | 立即检查并更新配置表和世界地图 |

完整 `npm test` 需要本机游戏协议包。可先在电脑版微信中打开游戏，或设置 `CW_PROTO_BUNDLE` 指向自己的 `_src_chunks_.wxapkg` 或解包后的 `game.js`。离线回归使用显式测试数据，真实协议回归继续检查当前游戏包兼容性。

端口、浏览器、资源更新间隔和其他开发命令见使用指南。[启动参数](docs/console-guide.md#启动参数) · [资源自动更新](docs/console-guide.md#资源自动更新) · [开发与辅助命令](docs/console-guide.md#开发与辅助命令)
